# Agrasen Yoga & Karate Classes — Next.js Website

A responsive one-page website built with Next.js App Router and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Open Vercel and import the GitHub repository.
3. Framework preset: Next.js.
4. Build command: `npm run build`
5. Output: leave default.
6. Deploy.

## Before going live

- Replace the WhatsApp number if needed.
- Confirm the exact Google Maps location.
- Add the final class timings and fees.
- Add any additional karate-specific photos when available.
